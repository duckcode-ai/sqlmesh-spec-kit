# /sqlmesh.specify

Create or revise `specs/<NNN>-<slug>/spec.md`.

1. Read `.sqlmesh-specify/constitution.md` and relevant project conventions.
2. Translate the request into business intent, affected SQLMesh concepts, and downstream impact.
3. Write EARS acceptance criteria only in the Acceptance Criteria section.
4. Set status to `draft` until a human explicitly approves it.
5. Do not write a plan or tasks from an unapproved spec.
