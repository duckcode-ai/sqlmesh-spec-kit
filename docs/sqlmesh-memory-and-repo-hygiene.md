# SQLMesh Memory and Repo Hygiene

Keep:

- `.sqlmesh-specify/constitution.md`
- approved `spec.md`, `plan.md`, `tasks.md`, review notes, and reports
- concise project convention skills
- sanitized Jira and Confluence context needed for implementation

Do not keep:

- raw agent scratch work
- secrets or credentials
- production data samples
- stale plan output superseded by final review evidence

Specs and plans are memory because they explain why a model exists, what boundaries were approved, and what SQLMesh evidence made the change safe to promote.
